📚 How this version works Quick reference notes ?

Saved filters: Money Nest now remembers the last filter/sort dropdowns you chose on Calendar, Bills, transaction ledgers, and account forecast views. Search text is temporary and will not hide things later.

Account forecast range: Removed All Forecast because very long recurring schedules could freeze the Accounts page. Use Next 90 days for the longest saved forecast window.

Calendar filter: view All, Mak Checking, Ty Checking, Joint Checking, etc.

Actual balance uses cleared transactions only.

Projected balance uses cleared + planned transactions.

Bills page: recurring transactions live in one place so yearly, bi-weekly, weekday-based, last-day-of-month, and odd recurring bills are easier to manage.

Add transaction: the form is grouped into collapsible sections so you only deal with the basics first. Autofill templates only apply title/category/notes and will not change type/status/account routing.

Paychecks: use the Paycheck type for true paychecks. Regular Income can be used for Venmo, cash, refunds, etc. without affecting safe-to-spend.

Dates: Money Nest uses your browser's local date so late-night use does not accidentally roll into tomorrow because of UTC time.

Safe to spend: On payday, paycheck accounts now use the following paycheck as the horizon, so Safe to Spend does not collapse to only today’s leftover balance.

Recent changes: Settings has a Recent Changes section that can undo saved local edits going forward. JSON backup/cloud imports are handled separately from undo history so restore files do not create huge change snapshots. CSV is best for batch editing existing data; import Accounts/Debts/Categories before Transactions if rebuilding from empty.

Recurring cleared status: Mark cleared / mark planned applies only to the clicked occurrence. Recurring templates stay planned by default, and individual cleared dates are stored as occurrence overrides.

Debt balances: Starting Balance is the default tracking baseline. For loans and medical payment plans, Statement/Current Balance + Date can be used as the live lender/provider baseline.

BNPL installment status: Buy Now, Pay Later accounts infer Planned/Complete from their linked installment schedule when no manual status is set.

Loan payoff forecast: Auto loans can estimate principal/interest/fees from cleared payments that have a breakdown.

Credit cards: credit rows show Available Credit and Debts includes by-owner utilization summaries with a payoff simulator.

Debt workflows: Use Card Instead and Create Card Payment help connect cash plans, card charges, payments, and optional IOUs/reimbursements.

Statements: Statement Balance is separate. Use “Reset tracking baseline to this statement” when you want the statement balance/date to become the new Current Balance baseline.

Categories: emojis/colors show on the calendar and account/debt ledgers.
