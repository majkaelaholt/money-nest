How this version works Quick reference notes ?

Saved filters: Money Nest now remembers the last filter/sort dropdowns you chose on Calendar, Bills, transaction ledgers, and account forecast views. Search text is temporary and will not hide things later.

Account forecast range: Removed All Forecast because very long recurring schedules could freeze the Accounts page. Use Next 90 days for the longest saved forecast window.

Calendar filter: view All, Mak Checking, Ty Checking, Joint Checking, etc.

Actual balance uses cleared transactions only.

Projected balance uses cleared + planned transactions.

Bills page: recurring transactions live in one place so yearly, bi-weekly, weekday-based, last-day-of-month, and odd recurring bills are easier to manage.

Add transaction: the form is grouped into collapsible sections so you only deal with the basics first. Autofill templates only apply title/category/notes and will not change type/status/account routing.

Paychecks: use the Paycheck type for true paychecks. Regular Income can be used for Venmo, cash, refunds, etc. without affecting safe-to-spend.

Safe to spend: On payday, paycheck accounts now use the following paycheck as the horizon, so Safe to Spend does not collapse to only today’s leftover balance.

Recent changes: Settings has a Recent changes section that can undo saved edits going forward. JSON backup import is handled separately from undo history so restore files do not create huge change snapshots. CSV is best for batch editing existing data; import Accounts/Debts/Categories before Transactions if rebuilding from empty.

Recurring cleared status: Mark cleared / Mark planned now applies only to the clicked occurrence. Recurring templates stay planned by default, and individual cleared dates are stored as occurrence overrides.

Debt balances: Starting Balance is the default tracking baseline. For loans and medical payment plans, Statement/Current Balance + Date can be used as the live lender/provider baseline, so Current Balance starts from the latest provider balance and only counts cleared activity after that date.

BNPL installment status: Buy Now, Pay Later accounts now infer Planned/Complete from their linked installment schedule when no manual status is set, and their Installment Status can be edited like other debt payment statuses.

Loan payoff forecast: Auto loans can estimate principal/interest/fees from cleared payments that have a breakdown. Planned/recurring loan payments and blank cleared recurring payments can use that estimate, while manual payment breakdowns still override it.

Credit cards: the Credit Line card and debt-list account rows show Available Credit using credit limit minus current balance.

Debts page: each debt type section has Expand accounts / Collapse accounts buttons that only open or close the accounts inside that type.

Debt spending: enter an expense directly on a credit card/Klarna/loan account to increase its balance.

Debt payments: monthly payment totals use minimum/monthly due + manual extra by default. Enter a cleared transfer from cash and link a debt to reduce Current Balance; debt detail ledgers show those payments as positive/green.

Use card instead: right-click a planned cash expense and choose “Use card instead” to keep the spending category/cash plan, create the card charge on the purchase date, and schedule the card payment for a separate payment date.

Create card payment: right-click an existing credit-card purchase and choose “Create card payment” to create the cash-account payment afterward. You can also create a pending IOU/reimbursement in the same flow when another account fronted the payment.

Pending reimbursements: use IOU / reimbursement on an account when one account fronts money and another will pay it back later. The paying account plans for money leaving, while the receiving account shows the expected reimbursement but does not count it as available until cleared.

Statements: Statement Balance is kept separate. Use “Reset tracking baseline to this statement” when you want the statement balance/date to become the new Current Balance baseline.

Categories: emojis/colors show on the calendar and account/debt ledgers.
